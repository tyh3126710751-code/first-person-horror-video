# 剧本与主观视角

在从想法起稿、校正现成剧本或反馈牵动剧情时读取。剧本是设定和分镜的依据，先让故事可拍、连贯、符合用户意图，再考虑平台解析。平台自动拆解结果不能代替剧本自检。

## 选择故事与模式

- 没有具体故事时，给 2–3 个场景、威胁机制和结局明显不同的第一人称方向供选择；已有核心情节时直接完善，不重新提案。
- 主线是恐怖压力引发逃跑并成功脱险时选**标准模式**。约 80 秒的起稿可参考：5–10 秒进入故事，30–40 秒恐怖氛围并形成逃跑意图，约 20 秒受阻逃跑，15–20 秒脱险、确认安全、放缓呼吸。范围可调整，时间段须连续；最后一段不再奔跑。
- 其他沉浸式恐怖故事选**创作模式**，用用户设定的时长和结局组织紧张变化。封闭电梯、无法脱身、悬疑留白等故事不能为了公式被写成逃跑成功。
- 用户明示模式、节奏、台词或结局时遵循用户。未指定时，约 80 秒、4:3、无台词／字幕／配乐只是可修改的起稿值。

创作模式中的受限姿态故事，身体位置变化很少时，可从行动范围、可见区域、声源和光源的变化检查紧张升级。每次变化写出可感知的物理触发和后续继承，例如遮挡形成后视野如何受限、原光源消失后还能看见什么；画外事件通过实际可听或可见的结果进入双眼视角。阶段数量、变化顺序和结局由故事决定，不强制逐项失去这些条件或以黑屏收尾。

## 严格自检

成稿前逐场核对并修正；无法确定的重要事实列给用户，而不暗中发明。

1. **因果**：每次威胁、反应、障碍和转机有可感知的前因；主角为何前进、停下、转身或改变目标能从画面与声音理解。
2. **主观可拍性**：摄影机始终在主角双眼位置。背后事件先以声音或可见反射提示，转身后才能看到；自己的手、袖口、腿脚须自然入画，不用外部机位拍自己的正脸、背影或全身。用户安排镜面或屏幕时，可以从双眼视角看到其中的自己。
3. **空间连续性**：画出主角朝向、门与障碍的左右前后、威胁来源、入口出口及转身后的方位。门的形制、开启方向和道具归属跨场不变；掉落的物件不能无故回到手里。
4. **动作与时间**：把多步行动写出先后、接触和结果。每段时长足以完成动作，时间码不重叠、不留空，合计等于目标时长。
5. **体验与结局**：标准模式检查恐怖积累、受阻逃跑和安静脱险收束；创作模式检查恐怖线索如何升级及结尾是否符合既定创意。声音、光线与情绪须对应可听可见的物理现象。

交付剧本时附简短自检结论：模式与理由、总时长、通过的关键项、仍需用户决定的事实。已有剧本只提出必要局部改写，保留已确定的情节和结局。

## 剧创剧本格式

依据用户提供的《提取Skill需要的材料》整理为便于手动上传的**纯文本剧本块**：顶部写《剧名》、剧情简介、人物小传；正文写集数、唯一场次号、时间（日／夜）＋内外景＋地点、人物、逐段画面。场次号、字段名和时间码不要加 Markdown 粗体、标题符或表格标记，避免复制到平台后解析歧义。动作可用 △ 开头；有台词时写“人物（可选情绪）：台词”。需要画外音或独白时明确标注。不要为了补格式凭空加入会被念出的台词；无台词剧本若遇平台实际解析错误，再根据页面反馈修订。

    《剧名》
    剧情简介：……
    人物小传：主角为双眼视角，只让自然可见的身体局部入画。

    第一集
    1-1 夜 内 地点
    人物：主角、实际出镜角色
    △00:00—00:08。主角此刻面朝哪里、实际看见什么，按顺序发生的动作及声音。

用户手动上传后，若提供解析结果，对照剧名、场次、角色、道具、台词、结局和时长查偏差，修正受影响的部分。平台材料中的示例结构可借鉴；故事内容和错误镜位不可照搬。
