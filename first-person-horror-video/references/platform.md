# 剧创手动交接与项目状态

默认由用户在火山剧创完成项目创建、剧本上传、设定图上传、素材绑定、提示词提交和视频生成。Codex 提供可执行材料及核对清单，不把文本交付称为平台操作完成。平台入口与功能以[剧创官方文档](https://docs.volcengine.com/docs/drama-creation/short-play-creation?lang=zh)和用户当前编辑器为准；旧项目的编辑器、模型和可用模式可能不同。

## 交接给用户

1. **剧本**：交已确认的上传文本，并提示用户上传后核对剧名、场次、角色、道具、时长和结局。用户反馈解析偏差时，先修剧本或平台骨架对应部分；不要让自动拆解改写已确认的情节。
2. **设定图**：交每个资产的图片文件、ID、平台显示名、一句介绍及衍生关系。提示用户按表手动上传，核对页面缩略图、名称、主图／衍生图；未收到核实结果时状态写“待上传／待绑定”。
3. **分镜**：交全片骨架、逐镜提示词及资产对应表。用户应在编辑器先把实际素材加入对应分镜，再粘贴提示词，检查名称关联、首尾帧模式、时长、画幅、模型和保存结果。官方文档说明编辑器可按名称关联已加入该镜的图，也支持精确 @ 与首尾帧模式；自动关联仍需在页面核对。
4. **视频**：用户自行选择生成参数与次数。需要反馈时请其提供镜号、视频或截图／时间点、观察到的问题及当前提示词版本；若有平台链接也记录。Codex 不替用户按下生成，不从余额变化推断哪一版已获验收。

用户若只提供“按键错了”一类反馈，可先根据已有项目记录分析，再只索取定位所必需的镜号／证据；不要求重复提交整套材料。若用户以后明确委托 Codex 操作剧创，按那次请求的范围和当前页面事实处理，不能把本 skill 的手动流程当作已发生的操作。

## 可恢复的记录

在项目目录维护 `00_项目状态.md`，记录模式、剧本版本与确认、画幅／目标时长／声音偏好、平台项目链接（若用户提供）、设定图的实际路径与确认／上传状态、全片分镜版本、每镜提示词版本与是否已提交、用户提供的生成结果和下一步。项目已有文件命名时沿用，不强行重排。状态条目示例：

    剧本：v2，已确认；平台解析结果尚未提供
    C01：assets/C01_夜班护工_v1.png，图片已确认；用户上传状态待核实
    SH01：提示词 v3 已交付；平台保存状态待核实；用户报告 v2 视频按错 4 键
    证据：00:03 截图显示指腹接触 4；00:04 仅 7 亮；完整音频未核查
    下一步：用户核对 C01／P02 绑定并提交 SH01 v3 后反馈生成结果

用户从失败片段直接进入且缺少旧状态时，建立“已知／待核实”最小记录：当前镜号与时长、旧 prompt 来源、实际绑定图、前镜尾帧、本镜视频证据、用户目标。未知来源不伪装为已确认；完成文本修订也不代表新视频已经生成。

## 回读平台修改

用户要求核对网页修改，或提供页面原文／截图时，保留交付版、当前编辑器原文、实际分镜 ID、采集日期、所见模型、生成模式、配置时长、输出画幅、分辨率和参考素材。区分“当前已保存编辑文本”“该视频生成时的文本与参数”“用户最终采用的视频版本”；没有生成记录证明对应关系时标为待核实。项目页当前模型、配置时长和视频封面不证明历史视频使用了这些参数，也不证明完整动作和声音。

素材引用芯片造成的换行／空白可在比较副本中归一化，原文保留。粘贴后由用户或获授权的网页操作回读正文与配置，检查画幅冲突、名称关联和 Markdown 围栏等包外残留；删掉包外标题时仍保留骨架中的镜号与配置时长。只改编辑器而未重新生成的视频仍关联旧版本；模型、参考图或参数同时变化时，不把效果单独归因于提示词。来源视频尾帧与首尾帧生成模式的区别见 [分镜与帧参考](shots.md)。

视频费用由用户在平台决定。用户若询问报价，依据其当前页面或可靠官方计费资料说明参数和来源；取不到就说无法可靠估算，不填造积分数。
